# foodPollBot

Спасаем Никитоса от создания опросов вручную.

Бот раз в день (по будням) присылает в группу **кастомные опросы** по категориям
(первое, второе, гарнир, салат), собирает голоса, а вечером публикует
сгруппированный результат и раскладку «кто что взял».

## Что умеет

### В группе — минимум шума
Только три вещи: опросы, результаты и сообщение **«Выберите действие»**.
Больше бот в чат ничего не пишет (исключение — предупреждения об изменении
меню, см. ниже).

* **Кастомные опросы.** Обычные сообщения с инлайн-кнопками (не нативные
  Telegram-опросы) — по кнопке на вариант, счётчик голосов на кнопке, выбор
  один на категорию, повторное нажатие снимает голос. Свой голос
  подсвечивается 🟢. Голоса хранятся на стороне бота (`poll_state.json`),
  поэтому переживают перезапуск и поддаются правке.
* **Сгруппированный результат:** первые блюда и салаты — обычным подсчётом;
  второе и гарнир не по отдельности, а комбинациями **«Вторые блюда +
  гарниры»**; ниже — раскладка «по людям» (первое + второе + гарнир + салат).
  Под результатом строка «Обновил(а) _имя_ в _чч:мм_».
* **«Выберите действие»** появляется после каждого набора опросов и после
  обновления результатов:
  * `🔄 Обновить результаты` — сгруппированный результат на день;
  * `🔁 Мне как обычно` — голосует за вас по статистике (см. ниже).
    **Кнопка скрыта первые ~2 недели** — пока по каждому буднему дню не
    пройдёт минимум по 2 опроса (`config.json → poll_rounds`);
  * `✍️ Написать боту` — ссылка на личку, чтобы бот мог писать вам в ЛС.

### «Мне как обычно»
Голосует по вашей истории заказов (`orders_history.json`, ключи — ISO-даты),
**с учётом дня недели**:

* для каждой категории берётся самый частый ваш выбор **именно в этот день
  недели** за последние 4 недели;
* если этого блюда нет в сегодняшнем меню — следующий по частоте: сначала из
  «этого дня недели», потом из общей статистики за все дни;
* если по этому дню недели у вас меньше 2 заказов — в ЛС помечает, что взял
  из общей статистики;
* результат уходит в ЛС списком (что заменено на что — отдельной строкой);
* если вы ни разу не писали боту в ЛС — всплывающая подсказка нажать
  «Написать боту».

### Админ-панель (в личке с ботом)
Открывается кнопкой `⚙️ Админ-панель` в личном меню (`/start` в ЛС).

* **⏰ Время опроса** — ЧЧ:ММ, сохраняется в `config.json`, подхватывается
  планировщиком на лету.
* **📋 Меню по дням** — день недели → категория → отметить галочками, какие
  блюда из общей базы попадут в опрос этого дня.
* **🍽 База блюд** — общий справочник всех блюд по категориям: добавить / удалить.
* **🔄 Синхронизировать из schedule.json** — перезаписать меню всех дней из
  шаблона и дополнить базу блюд.

### Правка меню после отправки опроса
Если опрос на этот день недели уже висит в группе, сохранение изменений в
админ-панели:

* обновляет кнопки живого опроса (голоса за убранные блюда снимаются);
* шлёт в группу предупреждение —
  `⚠️ Изменения в меню — <категория> (<дата>): • заменено «X» → «Y» …
  Пожалуйста, переголосуйте.`

## Файлы данных

| файл | назначение | в git |
|------|------------|-------|
| `schedule.json` | недельный шаблон меню | да |
| `dishes.json` | общая база блюд по категориям | да |
| `orders_history.json` | история заказов пользователей (ISO-даты) | да |
| `config.json` | время опроса, меню по дням, счётчик опросов `poll_rounds` | нет |
| `poll_state.json` | живые опросы и голоса | нет |
| `dm_users.json` | кто писал боту в ЛС | нет |

При первом запуске `dishes.json` и меню в `config.json` заполняются из
`schedule.json`; старый формат `orders_history.json` (`дд.мм`) один раз
мигрирует в ISO-даты.

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

`.env` (см. переменные в `app/config.py`): `BOT_TOKEN`, `CHAT_ID`,
`TIMEZONE`, `POLL_START_HOUR`/`POLL_START_MINUTES` (стартовое время, дальше
меняется в админке), `POLL_SHIFT`, `RESULTS_HOUR`/`RESULTS_MINUTE`.

## Архитектура

```
bot.py                тонкая точка входа
app/
  config.py           переменные окружения + константы
  storage.py          атомарный JSON-слой хранения
  dishes.py           общая база блюд
  menu_config.py      время опроса + меню по дням, синк из schedule.json
  polls.py            движок кастомных опросов
  stats.py            история заказов + «мне как обычно»
  menu.py             меню «Выберите действие»
  admin.py            админ-панель в личке
  scheduler.py        суточный цикл (опросы утром, результаты в 18:00)
  bot.py              FoodPollBot — связывает хендлеры с модулями
```
