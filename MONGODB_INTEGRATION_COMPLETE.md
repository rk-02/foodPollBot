# 🚀 Быстрый старт с MongoDB для FoodPollBot

## ✅ Все готово к использованию!

Ваша интеграция с MongoDB успешно создана и протестирована. Вот что было реализовано:

### 📦 Компоненты

1. **MongoDB Storage** (`infrastructure/mongo_storage.py`)
   - Асинхронное подключение к MongoDB
   - CRUD операции для опросов и голосов
   - Автоматическое создание индексов

2. **Menu Manager** (`infrastructure/menu_manager.py`)
   - Управление меню из schedule.json
   - Агрегация результатов голосования
   - Управление пользовательскими комбинациями

3. **Configuration** (`infrastructure/config.py`)
   - Централизованная конфигурация
   - Загрузка настроек из .env

4. **Migration Utility** (`migrate_to_mongo.py`)
   - Перенос данных из JSON в MongoDB
   - Тестирование подключения
   - Просмотр конфигурации

### 🔧 Следующие шаги

#### 1. Установите MongoDB

**Опция A: MongoDB Community Server**
```bash
# Скачайте с https://www.mongodb.com/try/download/community
# Установите с настройками по умолчанию
```

**Опция B: MongoDB через Docker**
```bash
docker run --name mongodb -d -p 27017:27017 mongo:7.0
```

#### 2. Настройте .env файл

Обновите ваш `.env` файл:
```env
# Добавьте ваш настоящий токен бота
BOT_TOKEN=1234567890:ВАША_СТРОКА_ТОКЕНА

# Обновите Chat ID на настоящий
CHAT_ID=-1001234567890

# MongoDB настройки (по умолчанию подходят для локальной установки)
MONGO_URL=mongodb://localhost:27017
MONGO_DB_NAME=foodpoll_bot
MONGO_CONNECTION_TIMEOUT=10000
```

#### 3. Запустите миграцию

```bash
# Тест подключения (ПОСЛЕ установки MongoDB)
python migrate_to_mongo.py test

# Миграция данных из schedule.json
python migrate_to_mongo.py migrate
```

#### 4. Запустите бота

```bash
python add_poll_by_day.py
```

### 📊 Что изменилось в боте

- ✅ **Совместимость**: Бот работает с существующими данными в памяти И с MongoDB
- ✅ **Fallback**: Если MongoDB недоступен, бот продолжает работать в legacy режиме
- ✅ **Автоматическая синхронизация**: Все голоса автоматически сохраняются в MongoDB
- ✅ **Улучшенная отчетность**: Результаты могут загружаться как из памяти, так и из базы данных

### 🆘 Если что-то не работает

1. **MongoDB не найден**:
   ```bash
   # Проверьте, запущен ли MongoDB
   # Windows: откройте Task Manager, найдите "mongod"
   # Или попробуйте подключиться через командную строку
   mongo
   ```

2. **Ошибки подключения**:
   ```bash
   # Проверьте конфигурацию
   python migrate_to_mongo.py config
   
   # Протестируйте подключение
   python migrate_to_mongo.py test
   ```

3. **Бот не запускается**:
   ```bash
   # Проверьте токен бота в .env
   # Убедитесь, что все зависимости установлены
   pip install -r requirements.txt
   ```
